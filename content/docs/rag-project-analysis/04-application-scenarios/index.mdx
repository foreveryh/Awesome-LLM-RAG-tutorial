| 企业知识库 | SurfSense | 向量+BM25 混合检索、RRF 融合、轻量重排 | [SurfSense 深度解析](/docs/rag-project-analysis/04-key-projects-analysis/surfsense) |

| 代码库问答 | SurfSense + LightRAG | 混合检索 + 自定义分块/重排 | [SurfSense](/docs/rag-project-analysis/04-key-projects-analysis/surfsense)、[LightRAG](/docs/rag-project-analysis/04-key-projects-analysis/lightrag) |

## 使用建议

- 先在本章选定目标场景与能力清单，再跳转对应项目深挖实现细节
- 若出现“表现与预期不符”，回到 Pipeline 深度剖析与参数网格章节对症调参
- 企业落地优先关注 onyx；多模态优先关注 ragflow；轻量个人优先 LightRAG；混合检索关注 SurfSense
